# Day 24 — Python Decorators

**Module:** Advanced Python Concepts  
**Learning path:** Complete Python — 50 Days

## 1. Overview
A decorator wraps a function to add behavior without changing the function's main code. Decorators are commonly used for logging, timing and access checks.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Functions are first-class objects in Python.
- A decorator accepts a function and returns a wrapper or another callable.
- @decorator is convenient syntax for function decoration.
- Use functools.wraps to preserve function metadata.

## 3. Key concepts

### Concept 2

### Concept 3
