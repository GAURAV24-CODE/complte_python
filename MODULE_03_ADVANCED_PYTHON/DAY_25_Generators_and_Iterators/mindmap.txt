DAY 25: Generators and Iterators
|
+-- OVERVIEW
|   +-- Iterators produce values one at a time. Generators make iterators using yield, which can reduce memory use for large sequences.
|
+-- CORE CONCEPTS
|   +-- iter() obtains an iterator; next() requests its next value.
|   +-- A generator function uses yield.
|   +-- Generator expressions use parentheses.
|   +-- Generators are useful for streaming or large data.
