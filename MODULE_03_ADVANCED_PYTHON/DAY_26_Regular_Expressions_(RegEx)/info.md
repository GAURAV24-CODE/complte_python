# Day 26 — Regular Expressions (RegEx)

**Module:** Advanced Python Concepts  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Regular expressions describe text patterns. Python's re module supports searching, matching, splitting and substitution.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- re.search finds a match anywhere in text.
- re.match checks from the beginning; re.fullmatch checks the entire string.
- Character classes and quantifiers describe patterns.
- Use raw strings such as r'\d+' for regex patterns.
