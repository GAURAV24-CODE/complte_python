DAY 27: Multithreading and Multiprocessing
|
+-- OVERVIEW
|   +-- Concurrency helps structure work that can overlap. Threads share process memory and are often useful for I/O-bound tasks; processes have separate memory and can help with CPU-bound work.
|
+-- CORE CONCEPTS
|   +-- threading creates threads within one process.
|   +-- multiprocessing creates separate processes.
|   +-- Use the main guard for multiprocessing-safe scripts.
|   +-- Choose concurrency based on workload and measure performance.
