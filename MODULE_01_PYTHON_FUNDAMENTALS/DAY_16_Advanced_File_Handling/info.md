# Day 16 — Advanced File Handling

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Work with paths, encodings, binary files and safe file operations. pathlib provides an object-oriented way to work with filesystem paths.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Use pathlib.Path for portable paths.
- Choose an explicit encoding such as UTF-8 for text.
- Binary modes use b, for example rb and wb.
- Check exists() and create directories with mkdir().
