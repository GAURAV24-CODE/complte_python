# Day 05 — Loops — for  loops

**Module:** Python Fundamenta
**Learning path:** Complete Python — 50 Days

## 1. Overview
Loops repeat a block of code. Use for to iterate over a sequence and while to repeat while a condition remains true.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- for iterates over items in an iterable.
- range(start, stop, step) generates integer sequences.
- while repeats while its condition is true.
- break exits a loop; continue skips to the next iteration.

## 3. Key concepts
### Concept 1
for iterates over items in an iterable.
### Concept 2
range(start, stop, step) generates integer sequences.
### Concept 3
while repeats while its condition is true.
### Concept 4
break exits a loop; continue skips to the next iteration.
