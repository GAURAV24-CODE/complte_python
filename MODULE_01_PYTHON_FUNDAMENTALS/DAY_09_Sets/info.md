# Day 09 — Sets

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Sets are unordered collections of unique elements. They are useful for removing duplicates and performing mathematical set operations.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Sets remove duplicate values automatically.
- Sets do not support positional indexing.
- Use add() and discard() to update a set.
- Union, intersection, difference and symmetric difference compare sets.

## 3. Key concepts
### Concept 1

### Concept 2

### Concept 3

### Concept 4
Union, intersection, difference and symmetric difference compare sets.
