# Day 04 — Conditional Statements

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Conditional statements choose which code runs based on whether a condition is true. Use if, elif and else, with correct indentation.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- if runs a block when its condition is true.
- elif checks another condition if earlier conditions failed.
- else handles all remaining cases.
- Indentation defines the block.

## 3. Key concepts
### Concept 1
if runs a block when its condition is true.
### Concept 2
elif checks another condition if earlier conditions failed.
### Concept 3
else handles all remaining cases.
### Concept 4
Indentation defines the block.
