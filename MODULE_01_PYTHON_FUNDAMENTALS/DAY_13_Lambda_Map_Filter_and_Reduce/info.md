# Day 13 — Lambda, Map, Filter and Reduce

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
These tools support compact functional-style transformations. Use lambda for short functions, map for transformation, filter for selection and reduce for cumulative aggregation.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- lambda creates a small anonymous function.
- map applies a function to each item.
- filter keeps items that pass a condition.
- functools.reduce combines items cumulatively.

## 3. Key concepts
### Concept 1

### Concept 2

### Concept 3

### Concept 4
functools.reduce combines items cumulatively.
