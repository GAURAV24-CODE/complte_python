## 1. Overview
Strings are immutable sequences of Unicode characters. Learn indexing, slicing, common methods, formatting and joining.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Use single, double or triple quotes.
- Indexing starts at 0; negative indexes count from the end.
- Slicing uses [start:stop:step].
- Common methods include lower(), upper(), strip(), replace() and split().
