# Day 15 — File Handling

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
File handling lets programs read and write persistent data. Use with open(...) so files are closed reliably.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- open() supports modes such as r, w, a and x.
- read(), readline() and readlines() read content.
- write() writes text; use newline characters for line breaks.
- with manages file closing automatically.
