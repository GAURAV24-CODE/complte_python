# Day 03 — Operators

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Operators perform calculations, comparisons and logical combinations. Understand arithmetic, assignment, comparison, logical, membership and identity operators.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Arithmetic: +, -, *, /, //, %, **.
- Comparison operators return booleans.
- and, or and not combine conditions.
- in checks membership; is checks object identity.
