# Day 10 — Dictionaries

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Dictionaries store key-value pairs. They provide fast key-based lookup and are commonly used for structured records.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Create dictionaries with {key: value}.
- Keys must be hashable and unique.
- Use get() for safe lookup.
- keys(), values() and items() support iteration.
