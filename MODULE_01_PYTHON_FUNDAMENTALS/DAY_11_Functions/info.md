# Day 11 — Functions

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Functions package reusable logic. Define them with def, give them meaningful names and call them when needed.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- def defines a function.
- Parameters receive input values.
- A function can contain multiple statements.
- return sends a result back to the caller.

## 3. Key concepts
### Concept 1
def defines a function.
### Concept 2
Parameters receive input values.
### Concept 3
A function can contain multiple statements.
### Concept 4
return sends a result back to the caller.
