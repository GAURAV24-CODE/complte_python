# Day 17 — Working with Date and Time

**Module:** Python Fundamentals  
**Learning path:** Complete Python — 50 Days

## 1. Overview
The datetime module handles dates, times, durations and formatting. Use date and datetime objects instead of manually manipulating date strings.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- date represents a calendar date.
- datetime represents date and time.
- timedelta represents a duration.
- strftime formats dates; strptime parses date strings.

## 3. Key concepts
### Concept 1
date represents a calendar date.
### Concept 2
datetime represents date and time.
### Concept 3
timedelta represents a duration.
### Concept 4
strftime formats dates; strptime parses date strings.
