# Day 34 — Web Scraping with BeautifulSoup

**Module:** Professional Python Development  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Web scraping extracts information from web pages. BeautifulSoup parses HTML; always respect site terms, robots guidance, privacy and rate limits.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- requests can retrieve HTML pages.
- BeautifulSoup parses HTML into a navigable tree.
- CSS selectors help locate elements.
- Web page structures can change; scraping may be restricted by site rules.
