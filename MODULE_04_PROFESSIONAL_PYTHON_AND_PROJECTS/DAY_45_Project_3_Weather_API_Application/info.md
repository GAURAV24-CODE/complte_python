# Day 45 — Project 3 — Weather API Application

**Module:** Real-World Projects  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Build a weather application that retrieves weather data from an API and presents a readable summary. Practice HTTP requests, JSON and error handling.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Choose a documented weather API and review its terms.
- Keep API credentials in environment variables if required.
- Handle invalid locations, timeouts and API errors.
- Display units and the data retrieval time.
