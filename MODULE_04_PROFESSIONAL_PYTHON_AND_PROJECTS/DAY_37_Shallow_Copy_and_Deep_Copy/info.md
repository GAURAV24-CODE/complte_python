# Day 37 — Shallow Copy and Deep Copy

**Module:** Advanced Python and Practical Skills  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Assignment creates another reference to an object. Shallow copies duplicate the outer container but share nested objects; deep copies recursively copy nested objects.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Use copy.copy for shallow copies.
- Use copy.deepcopy for recursive copies.
- Nested mutable objects reveal the difference.
- Immutable values behave differently from mutable containers.
