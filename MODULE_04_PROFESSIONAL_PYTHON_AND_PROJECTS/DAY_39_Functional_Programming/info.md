# Day 39 — Functional Programming

**Module:** Advanced Python and Practical Skills  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Functional programming emphasizes functions, predictable transformations and minimizing shared mutable state. Python supports functional techniques alongside other styles.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Pure functions return results without changing external state.
- Treat data as immutable where practical.
- Higher-order functions accept or return functions.
- map, filter, comprehensions and sorted(key=...) support transformations.

## 3. Key concepts

### Concept 2
