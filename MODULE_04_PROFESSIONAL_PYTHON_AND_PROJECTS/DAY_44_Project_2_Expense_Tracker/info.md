# Day 44 — Project 2 — Expense Tracker

**Module:** Real-World Projects  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Build an expense tracker that records transactions, categorizes spending and summarizes totals. Practice dates, data structures and file or database storage.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Represent each expense with amount, category, date and description.
- Validate positive amounts and valid dates.
- Calculate totals by category and month.
- Persist data in CSV, JSON or SQLite.
