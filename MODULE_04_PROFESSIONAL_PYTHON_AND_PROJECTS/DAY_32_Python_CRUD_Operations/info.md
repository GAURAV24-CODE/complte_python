# Day 32 — Python CRUD Operations

**Module:** Professional Python Development  
**Learning path:** Complete Python — 50 Days

## 1. Overview
CRUD means Create, Read, Update and Delete. Build these operations using SQL statements and parameterized queries.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Create uses INSERT.
- Read uses SELECT.
- Update uses UPDATE with a WHERE clause.
- Delete uses DELETE with a WHERE clause; always verify the target rows.

## 3. Key concepts
### Concept 1
Create uses INSERT.
### Concept 2
Read uses SELECT.
### Concept 3
Update uses UPDATE with a WHERE clause.
### Concept 4
Delete uses DELETE with a WHERE clause; always verify the target rows.
