# Day 33 — Working with APIs and HTTP Requests

**Module:** Professional Python Development  
**Learning path:** Complete Python — 50 Days

## 1. Overview
APIs let applications exchange data. HTTP requests use methods such as GET and POST, status codes and structured responses, often JSON.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- GET retrieves a resource; POST submits data.
- HTTP status codes communicate request outcomes.
- Requests is a popular third-party HTTP library.
- Handle timeouts and request exceptions; do not expose API keys.

## 3. Key concepts
