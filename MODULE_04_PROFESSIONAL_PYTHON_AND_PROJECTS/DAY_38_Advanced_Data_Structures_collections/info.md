**Module:** Advanced Python and Practical Skills

## 1. Overview
The collections module provides specialized containers such as Counter, defaultdict, deque and namedtuple for common data-handling patterns.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Counter counts hashable items.
- defaultdict supplies a default value for missing keys.
- deque supports efficient appends and pops at both ends.
- namedtuple creates tuple-like records with named fields.
