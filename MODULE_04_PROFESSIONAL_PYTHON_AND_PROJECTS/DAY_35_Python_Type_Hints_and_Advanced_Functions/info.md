# Day 35 — Python Type Hints and Advanced Functions

**Module:** Professional Python Development  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Type hints document expected types and help tools analyze code. They do not normally enforce types at runtime by themselves.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Annotate parameters and return values.
- Use list[str] and dict[str, int] for common collections.
- Optional values can be represented with str | None in modern Python.
- Functions can accept callables and return other functions.
