# Day 29 — Logging

**Module:** Professional Python Developme 
**Learning path:** Complete Python — 50 Days

## 1. Overview
Logging records events from a program at different severity levels. Debugging helps locate and understand defects systematically.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- Levels include DEBUG, INFO, WARNING, ERROR and CRITICAL.
- Use logging instead of scattered print statements in applications.
- Include useful context in log messages.
- Debug by reproducing the issue, inspecting state and testing a fix.

## 3. Key concepts
### Concept 1

### Concept 2

### Concept 3
