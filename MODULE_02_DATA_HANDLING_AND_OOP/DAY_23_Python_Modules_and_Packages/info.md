# Day 23 — Python Modules and Packages

**Module:** Data Handling and OOP  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Modules organize reusable Python code in files. Packages group related modules into directories and help structure larger applications.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- import module imports a module.
- from module import name imports a selected name.
- __name__ == '__main__' identifies direct script execution.
- A package is a directory of modules; __init__.py is commonly used to mark package structure.
