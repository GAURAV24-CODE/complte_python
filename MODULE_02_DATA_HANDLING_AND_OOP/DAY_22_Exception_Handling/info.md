# Day 22 — Exception Handling

**Module:** Data Handling and OOP  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Exceptions are runtime events that interrupt normal execution. Handle expected errors with try and except, and use finally for cleanup.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- try contains code that may raise an exception.
- except handles selected exception types.
- else runs when no exception occurred.
- finally runs whether an exception occurred or not; raise can signal invalid conditions.

## 3. Key concepts
