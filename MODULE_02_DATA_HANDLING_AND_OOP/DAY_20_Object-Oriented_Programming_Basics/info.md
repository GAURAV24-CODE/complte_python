**Module:** Data Handling and OOP  
**Learning path:** Complete Python — 50 Days

## 1. Overview
Object-oriented programming organizes code around classes and objects. A class defines a structure and behavior; an object is an instance of that class.

## 2. Learning objectives
By the end of this lesson, you should be able to:
- A class is a blueprint; an object is an instance.
- __init__ initializes instance attributes.
- self refers to the current instance.
- Methods are functions defined inside classes.

## 3. Key concepts
### Concept 1

### Concept 2
__init__ initializes instance attributes.
### Concept 3
self refers to the current instance.
### Concept 4
Methods are functions defined inside classes.
