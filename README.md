# COMPLETE_PYTHON — 50-Day Learning Repository

A structured Python learning path with fou modules and 50 day-wise less

## Folder structure
- `MODULE_01_PYTHON_FUNDAMENTALS` — Days 01–18
- `MODULE_02_DATA_HANDLING_AND_OOP` — Days 19–23
- `MODULE_03_ADVANCED_PYTHON` — Days 24–28
- `MODULE_04_PROFESSIONAL_PYTHON_AND_PROJECTS` — Days 29–50days

## Each day contains
- `code.ipynb` — Jupyter notebook with explanations, executable examples and exercises.
- `info.md` — Topic notes, key concepts, practice questions and revision checklist.
- `mindmap.txt` — Plain-text topic map for quick revision.

## How to use
1. Extract the ZIP file.
2. Open the folder in VS Code or Jupyter.
3. Start with Day 01 and work in order.
4. Read `info.md`, study `code.ipynb`, then revise `mindmap.txt`.
5. Complete the exercises before moving to the next day.

## Requirements
- Python 3
- Jupyter Notebook or VS Code with the Jupyter extension
- Some later lessons use optional packages such as `requests`, `beautifulsoup4` and `pandas`; install them in a virtual environment when needed.

## Learning note
Some API, web, and package examples require internet access or optional dependencies. Those cells are clearly marked. Use websites and APIs only in accordance with their terms and documentation.
